**Task**  
The provided code stub reads an integer, $n$, from STDIN. For all non-negative integers $i \lt n$, print $i^2$.  

**Example**  
$n = 3$  

The list of non-negative integers that are less than $n = 3$ is $[0, 1, 2]$.  Print the square of each number on a separate line.



0
1
4

**Input Format**

The first and only line contains the integer, $n$.

**Constraints**

$1 \le n \le 20$

**Output Format**

Print $n$ lines, one corresponding to each $i$.

**Sample Input 0**
    
    
     5
    

**Sample Output 0**
    
    
     0
    1
    4
    9
    16

================================================================================
--- SOLUTION & ALGORITHMIC ANALYSIS ---
ALGORITHMIC STRATEGY:
Loop through all non-negative integers from index 0 to N-1 and output the square of each index.

COMPLEXITY GUARANTEES:
- Worst-Case Time Complexity:  O(N)
- Auxiliary Space Complexity: O(1)

STANDALONE IMPLEMENTATION:
def print_squares():
    count = int(input().strip())
    for index in range(count):
        print(index ** 2)

if __name__ == '__main__':
    print_squares()
