--- PROBLEM DESCRIPTION ---
Reduce a string of lowercase characters in range `ascii[‘a’..’z’]`by doing a series of operations.  In each operation, select a pair of adjacent letters that match, and delete them.  

Delete as many characters as possible using this method and return the resulting string.  If the final string is empty, return `Empty String`

**Example**. 

$s = \text{'aab'}$  

`aab` shortens to `b` in one operation: remove the adjacent `a` characters. 

$s =\text{'abba'}$  

Remove the two 'b' characters leaving 'aa'.  Remove the two 'a' characters to leave ''.  Return 'Empty String'.


**Function Description**

Complete the *superReducedString* function in the editor below.   

superReducedString has the following parameter(s):  

- *string s:* a string to reduce  

**Returns**  

- *string:* the reduced string or `Empty String`

**Input Format**

A single string, $s$.

**Constraints**

- $1 \le \text{ length of }s \le 100$

**Sample Input 0**
    
    
     aaabccddd
    

**Sample Output 0**
    
    
     abd
    

**Explanation 0**

Perform the following sequence of operations to get the final string:
    
    
    aaabccddd → abccddd → abddd → abd
    

**Sample Input 1**
    
    
     aa
    

**Sample Output 1**
    
    
     Empty String
    

**Explanation 1**
    
    
    aa → Empty String
    

**Sample Input 2**
    
    
     baab
    

**Sample Output 2**
    
    
     Empty String
    

**Explanation 2**
    
    
    baab → bb → Empty String

================================================================================
--- SOLUTION & ALGORITHMIC ANALYSIS ---
ALGORITHMIC STRATEGY:
Maintain a character stack. For each character, if it matches the current top of the stack, pop the stack to eliminate the adjacent pair; otherwise push it.

COMPLEXITY GUARANTEES:
- Worst-Case Time Complexity:  O(L)
- Auxiliary Space Complexity: O(L)

STANDALONE IMPLEMENTATION:
def reduce_string(text: str) -> str:
    char_stack = []
    for ch in text:
        if char_stack and char_stack[-1] == ch:
            char_stack.pop()
        else:
            char_stack.append(ch)
    
    result = "".join(char_stack)
    return result if result else "Empty String"

if __name__ == '__main__':
    s = input().strip()
    print(reduce_string(s))
