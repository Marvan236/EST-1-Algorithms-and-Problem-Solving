--- PROBLEM DESCRIPTION ---
A *pangram* is a string that contains every letter of the alphabet.  Given a sentence determine whether it is a pangram in the English alphabet.  Ignore case.  Return either `pangram` or `not pangram` as appropriate.

**Example**  
$s = \text{'The quick brown fox jumps over the lazy dog'}$  

The string contains all letters in the English alphabet, so return `pangram`.

**Function Description**

Complete the function *pangrams* in the editor below.  It should return the string `pangram` if the input string is a pangram.  Otherwise, it should return `not pangram`.  

pangrams has the following parameter(s):

- *string s:* a string to test  

**Returns**  

- *string:* either `pangram` or `not pangram`

**Input Format**

A single line with string $s$.

**Constraints**

$0 \lt \text{ length of } s  \le 10^3$  
Each character of $s$, $s[i] \in \{a-z, A-Z, \textit{space}\}$

**Sample Input**

**Sample Input 0**

`We promptly judged antique ivory buckles for the next prize`

**Sample Output 0**

`pangram`

**Sample Explanation 0**

All of the letters of the alphabet are present in the string. 

**Sample Input 1**

`We promptly judged antique ivory buckles for the prize`

**Sample Output 1**

`not pangram`

**Sample Explanation 0**

The string lacks an `x`.

================================================================================
--- SOLUTION & ALGORITHMIC ANALYSIS ---
ALGORITHMIC STRATEGY:
Transform sentence into a set of lowercase characters and check whether all 26 ASCII English letters are present.

COMPLEXITY GUARANTEES:
- Worst-Case Time Complexity:  O(L)
- Auxiliary Space Complexity: O(1)

STANDALONE IMPLEMENTATION:
import string

def check_pangram(sentence: str) -> str:
    letters = set(sentence.lower())
    alphabet = set(string.ascii_lowercase)
    return "pangram" if alphabet.issubset(letters) else "not pangram"

if __name__ == '__main__':
    text = input().strip()
    print(check_pangram(text))
