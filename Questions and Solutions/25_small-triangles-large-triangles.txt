--- PROBLEM DESCRIPTION ---
You are given $n$ triangles, specifically, their sides $a_i$, $b_i$ and $c_i$. Print them in the same style but sorted by their areas from the smallest one to the largest one. It is guaranteed that all the areas are different.

The best way to calculate a area of a triangle with sides $a$, $b$ and $c$ is Heron's formula:

$S = \sqrt{p \times (p-a) \times (p-b) \times (p-c)}$ where $p={\frac {a+b+c} 2}$.

**Input Format**

The first line of each test file contains a single integer $n$. $n$ lines follow with three space-separated integers, $a_i$, $b_i$ and $c_i$.

**Constraints**

+ $1 \leq n \leq 100$
+ $1 \leq a_i,b_i,c_i \leq 70$
+ $a_i+b_i>c_i$,$a_i+c_i>b_i$ and $b_i+c_i>a_i$

**Output Format**

Print exactly $n$ lines. On each line print $3$ space-separated integers, the $a_i$, $b_i$ and $c_i$ of the corresponding triangle.

**Sample Input 0**
    
    
     3
    7 24 25
    5 12 13
    3 4 5
    

**Sample Output 0**
    
    
     3 4 5
    5 12 13
    7 24 25
    

**Explanation 0**

The area of the first triangle is 84 . The area of the second triangle is 30 . The area of the third triangle is 6 . So the sorted order is the reverse one.

--- SOLUTION & ALGORITHMIC ANALYSIS ---
ALGORITHMIC STRATEGY:
Sort an array of triangle structs by area. To avoid floating-point errors from sqrt(), sort based on 16 * Area^2 = (a+b+c)(a+b-c)(a-b+c)(-a+b+c) using 64-bit integer arithmetic and qsort.

COMPLEXITY GUARANTEES:
- Worst-Case Time Complexity:  O(N log N)
- Auxiliary Space Complexity: O(1) auxiliary

STANDALONE IMPLEMENTATION:
#include <stdio.h>
#include <stdlib.h>

typedef struct triangle {
    int a;
    int b;
    int c;
} triangle;

// Computes 16 * (Area)^2 to preserve integer precision
long long compute_area_metric(const triangle *t) {
    long long a = t->a, b = t->b, c = t->c;
    return (a + b + c) * (a + b - c) * (a - b + c) * (-a + b + c);
}

int triangle_comparator(const void *elem1, const void *elem2) {
    long long area1 = compute_area_metric((const triangle *)elem1);
    long long area2 = compute_area_metric((const triangle *)elem2);
    if (area1 < area2) return -1;
    if (area1 > area2) return 1;
    return 0;
}

void sort_by_area(triangle* tr, int n) {
    qsort(tr, n, sizeof(triangle), triangle_comparator);
}

int main() {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    triangle *arr = (triangle *)malloc(n * sizeof(triangle));
    for (int i = 0; i < n; ++i) {
        scanf("%d %d %d", &arr[i].a, &arr[i].b, &arr[i].c);
    }
    sort_by_area(arr, n);
    for (int i = 0; i < n; ++i) {
        printf("%d %d %d\n", arr[i].a, arr[i].b, arr[i].c);
    }
    free(arr);
    return 0;
}
