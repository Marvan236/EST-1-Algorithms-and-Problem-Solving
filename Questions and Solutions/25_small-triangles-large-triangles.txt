--- PROBLEM DESCRIPTION ---
You are given $n$ triangles, specifically, their sides $a_i$, $b_i$ and $c_i$. Print them in the same style but sorted by their areas from the smallest one to the largest one. It is guaranteed that all the areas are different.

The best way to calculate a area of a triangle with sides $a$, $b$ and $c$ is Heron's formula:

$S = \sqrt{p \times (p-a) \times (p-b) \times (p-c)}$ where $p={\frac {a+b+c} 2}$.

**Input Format**

The first line of each test file contains a single integer $n$. $n$ lines follow with three space-separated integers, $a_i$, $b_i$ and $c_i$.

**Constraints**

+ $1 \leq n \leq 100$
+ $1 \leq a_i,b_i,c_i \leq 70$
+ $a_i+b_i>c_i$,$a_i+c_i>b_i$ and $b_i+c_i>a_i$

**Output Format**

Print exactly $n$ lines. On each line print $3$ space-separated integers, the $a_i$, $b_i$ and $c_i$ of the corresponding triangle.

**Sample Input 0**
    
    
     3
    7 24 25
    5 12 13
    3 4 5
    

**Sample Output 0**
    
    
     3 4 5
    5 12 13
    7 24 25
    

**Explanation 0**

The area of the first triangle is 84 . The area of the second triangle is 30 . The area of the third triangle is 6 . So the sorted order is the reverse one.

--- SOLUTION & ANALYSIS ---
APPROACH / STRATEGY:
Sort an array of triangle structs by area using Heron's formula. To avoid floating-point inaccuracies, compare 16 * area^2 = (a+b+c)(a+b-c)(a-b+c)(-a+b+c) with 64-bit integers.

COMPLEXITY ANALYSIS:
- Time Complexity:  O(N log N)
- Space Complexity: O(1) auxiliary

SOURCE CODE:
#include <stdio.h>
#include <stdlib.h>

typedef struct triangle {
    int a;
    int b;
    int c;
} triangle;

// Computes 16 * Area^2 to avoid precision issues with floating point and square root
long long area_metric(triangle t) {
    long long a = t.a, b = t.b, c = t.c;
    return (a + b + c) * (a + b - c) * (a - b + c) * (-a + b + c);
}

int compare_triangles(const void *p1, const void *p2) {
    long long a1 = area_metric(*(const triangle *)p1);
    long long a2 = area_metric(*(const triangle *)p2);
    if (a1 < a2) return -1;
    if (a1 > a2) return 1;
    return 0;
}

void sort_by_area(triangle* tr, int n) {
    qsort(tr, n, sizeof(triangle), compare_triangles);
}

int main() {
    int n;
    if (scanf("%d", &n) != 1) return 0;
    triangle *tr = malloc(n * sizeof(triangle));
    for (int i = 0; i < n; i++) {
        scanf("%d%d%d", &tr[i].a, &tr[i].b, &tr[i].c);
    }
    sort_by_area(tr, n);
    for (int i = 0; i < n; i++) {
        printf("%d %d %d\n", tr[i].a, tr[i].b, tr[i].c);
    }
    free(tr);
    return 0;
}
