--- PROBLEM DESCRIPTION ---
You will be given a list of integers, $arr$, and a single integer $k$.  You must create an array of length $k$ from elements of $arr$ such that its *unfairness* is minimized. Call that array $arr'$.  Unfairness of an array is calculated as

$$max(arr') - min(arr')$$  

Where:  
- _max_ denotes the largest integer in $arr'.$  
- _min_ denotes the smallest integer in $arr'.$  
 
**Example**  

$arr = [1, 4, 7, 2]$  
$k = 2$     

Pick any two elements, say $arr' = [4, 7]$.  
$unfairness = max(4,7) - min(4,7) = 7 - 4 = 3$  
Testing for all pairs, the solution $[1, 2]$ provides the minimum unfairness.

**Note**: Integers in $arr$ may not be unique. 

**Function Description**

Complete the *maxMin* function in the editor below.  
maxMin has the following parameter(s):

- *int k:*  the number of elements to select  
- *int arr[n]:*: an array of integers   

**Returns**  

- *int:* the minimum possible _unfairness_

**Input Format**

The first line contains an integer $n$, the number of elements in array $arr$.  
The second line contains an integer $k$.  
Each of the next $n$ lines contains an integer $arr[i]$ where $0 \le i < n$.

**Constraints**

$2 \le n \le 10^5$  
$2 \le k \le n$  
$0 \le arr[i] \le 10^9$

--- SOLUTION & ALGORITHMIC ANALYSIS ---
ALGORITHMIC STRATEGY:
Sort the packet array in ascending order. Any optimal subset of size k will form a contiguous subsegment in the sorted array. Minimize arr[i + k - 1] - arr[i] with a sliding window of size k.

COMPLEXITY GUARANTEES:
- Worst-Case Time Complexity:  O(N log N)
- Auxiliary Space Complexity: O(N)

STANDALONE IMPLEMENTATION:
import sys

def minimize_unfairness():
    tokens = list(map(int, sys.stdin.buffer.read().split()))
    if not tokens:
        return
    n, k = tokens[0], tokens[1]
    elements = sorted(tokens[2:])

    # Slide a window of size k across the sorted values
    min_diff = min(elements[i + k - 1] - elements[i] for i in range(n - k + 1))
    print(min_diff)

if __name__ == '__main__':
    minimize_unfairness()
