--- PROBLEM DESCRIPTION ---
There is a sequence whose $n^{\text{th}}$ term is  
$$T_n = n^2 - (n-1)^2$$  

Evaluate the series  
$$S_n = T_1 + T_2 + T_3 + \cdots + T_n$$  
Find $S_n \bmod (10^9+7)$.  

**Example**  

$n = 3$  

The series is $1^2-0^2 + 2^2-1^2 + 3^2-2^2 = 1 + 3 + 5 = 9$.  

**Function Description**  

Complete the *summingSeries* function in the editor below.  

*summingSeries* has the following parameter(s):  

- *int n:* the inclusive limit of the range to sum  

**Returns**  

- *int:* the sum of the sequence, modulo $(10^9+7)$

**Input Format**

The first line of input contains $t$, the number of test cases.  
Each test case consists of one line containing a single integer $n$.

**Constraints**

+ $1 \le t \le 10$  
+ $1 \le n \le 10^{16}$

**Sample Input 0**
    
    
     2
    2
    1
    

**Sample Output 0**
    
    
     4
    1
    

**Explanation 0**

Case 1: We have 4=1+3   
Case 2: We have 1=1

================================================================================
--- SOLUTION & ALGORITHMIC ANALYSIS ---
ALGORITHMIC STRATEGY:
Term T_i = i^2 - (i - 1)^2 = 2i - 1. Sum of first N odd integers is S_N = sum(2i - 1) = N^2. Result is (N^2) % (10^9 + 7).

COMPLEXITY GUARANTEES:
- Worst-Case Time Complexity:  O(1)
- Auxiliary Space Complexity: O(1)

STANDALONE IMPLEMENTATION:
import sys

MODULO = 1000000007

def sum_series():
    tokens = sys.stdin.read().split()
    if not tokens:
        return
    results = []
    for token in tokens[1:]:
        n = int(token)
        results.append(str((n * n) % MODULO))
    sys.stdout.write("\n".join(results) + "\n")

if __name__ == '__main__':
    sum_series()
