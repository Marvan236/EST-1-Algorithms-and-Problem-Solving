## 📂 Syllabus Curriculum Breakdown

### 🔹 Unit 3: Fundamental Programming, Data Structures & Mechanics
1. **Data Types & I/O:** Stream formatting, bit-width ranges, type safety, fast standard I/O.
2. **Control Flow & Decision Logic:** Conditional branching, ternary logic, loop boundaries.
3. **Linear & Multi-Dimensional Arrays:** Inversion, linear accumulation, 2D hourglass convolution, matrix diagonals.
4. **Strings & Lexical Processing:** Word boundaries, stack-based adjacent cancellation, ASCII difference symmetry, alphabet hashing.
5. **Memory & Pointer Mechanics:** C/C++ memory addressing, dereferencing, in-place struct mutations.
6. **Dynamic Arrays:** Variable-sized 2D vectors, XOR sequence query dispatch.
7. **Pre-computation & Range Techniques:** Equilibrium index via prefix sums, difference array $O(1)$ range updates.
8. **Sliding Windows & Greedy Paradigms:** Window unfairness minimization, monotonic deque maximums.
9. **Bucketing & Frequency Arrays:** Linear counting sort, running median tracking with bounded frequency arrays.
10. **Recursion & Combinatorics:** Digital root reductions, subset power combinations, Davis staircase Tribonacci DP.
11. **Complexity & Sorting Analysis:** $O(\sqrt{N})$ prime verification, insertion sort shift/inversion counting.

### 🔹 Units 4 & 5: Mathematical Computing & Algorithms
1. **Greatest Common Divisor & Area Tiling:** Euclidean algorithm for optimal grid tiling.
2. **Number Theory & Multiples:** LCM and GCD constraints on integer sets.
3. **Modular Arithmetic:** Telescoping series closed-forms, Fermat's Little Theorem for huge powers.
4. **Permutations & Combinations:** Complete graph handshakes $\binom{N}{2}$, grid lattice paths $\binom{M+N-2}{M-1}$ with modular inverse factorials.
5. **Pascal's Triangle:** Dynamic computation of binomial coefficient tables modulo $10^9$.
