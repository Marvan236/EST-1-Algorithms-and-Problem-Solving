## 🎯 Syllabus & Topic Mapping

The 46 problems are mapped to the syllabus units and concepts as follows:

### 🔹 Unit 3: Programming Basics & Core Data Structures
- **Data Types & I/O:** Basic Data Types (C++), Java Datatypes, Input & Output (C++), Java Stdin & Stdout I
- **Operators & Branching:** Arithmetic Operators, Compare the Triplets, Python If-Else, Conditional Statements (C++)
- **Iteration & Loops:** Python Loops, C++ For Loop
- **Linear Arrays:** Simple Array Sum, Arrays - DS, Plus Minus
- **2D Arrays & Matrices:** 2D Array - DS (Hourglass), Diagonal Difference
- **Strings & Characters:** CamelCase, Super Reduced String, Funny String, Pangrams
- **Pointers & Memory:** C++ Pointer Pass-by-Reference, C Memory Pointers & Dereferencing
- **Functions:** C++ Functions (`max_of_four`), Python Leap Year Function
- **Structures:** C++ Structs, Small Triangles Large Triangles (Sorting Structures via Heron's Formula in C)
- **Dynamic Arrays:** Dynamic Array (2D XOR Queries), Variable Sized Arrays (C++ Jagged Vectors)
- **Pre-computation (Prefix Sums):** Sherlock and Array (Equilibrium Index), Array Manipulation (Difference Array Range Updates)
- **Sliding Window & Greedy:** Max Min (Angry Children), Deque-STL (Sliding Window Maximum with Monotonic Queue)
- **Bucketing / Frequency Arrays:** Counting Sort 1, Counting Sort 2, Fraudulent Activity Notifications (Running Median)
- **Recursion & Backtracking:** Recursive Digit Sum (Digital Root), The Power Sum (Subset Sum of Powers), Recursion: Davis' Staircase (Tribonacci DP)
- **Time & Space Complexity:** Time Complexity: Primality ($O(\sqrt{N})$), Running Time of Algorithms (Insertion Sort Inversions $O(N^2)$)

### 🔹 Units 4 & 5: Mathematical Foundations & Algorithms
- **Greatest Common Divisor (GCD) & Area Tiling:** Restaurant ($O(\log(\min(L, B)))$)
- **LCM & Number Theory:** Between Two Sets (Common Multiples & Divisors)
- **Modular Arithmetic:** Summing the N Series ($S_n = n^2 \pmod{10^9+7}$), Power of Large Numbers (Fermat's Little Theorem $A^B \pmod{10^9+7}$)
- **Permutations & Combinations:** Handshake (Pairwise Combinations $\binom{n}{2}$), Matrix Tracing (Grid Paths Combinatorics $\binom{m+n-2}{m-1}$)
- **Pascal's Triangle:** nCr Table (Combinatorial Sequence Generation modulo $10^9$)

## 💻 Compilation & Execution Guide (macOS)

All solutions are written as standalone executable programs that read from standard input (`stdin`) and write to standard output (`stdout`).

### 1. C++ Programs (C++14 / Clang)
Compile and run with Apple Clang:
```bash
clang++ -std=c++14 -O2 "Questions and Solutions/01_c-tutorial-basic-data-types.txt" -o solution_cpp
./solution_cpp
```

### 2. C Programs (Clang)
Compile and execute:
```bash
clang -O2 "Questions and Solutions/21_pointer-in-c.txt" -o solution_c
./solution_c
```

### 3. Java Programs (JDK 8 / 11 / 17 / 21)
Extract and compile the Java class:
```bash
# Save source as Solution.java and run
javac Solution.java
java Solution
```

### 4. Python 3 Programs
Execute directly using `python3`:
```bash
python3 -c "$(sed -n '/--- SOLUTION & ANALYSIS ---/,/==/p' 'Questions and Solutions/05_python-arithmetic-operators.txt' | sed '1,/SOURCE CODE:/d' | sed '$d')"
# Or extract the source code block to a .py file and run:
python3 solution.py
```
